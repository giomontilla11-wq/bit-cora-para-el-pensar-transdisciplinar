# El pensar transdisciplinar (I) — TP4

Recurso académico hipermedia de la Maestría en Educación Virtual, Universidad de Nariño.

## Publicar en GitHub Pages

1. Crea un repositorio nuevo en GitHub (puede ser público para GitHub Pages).
2. Sube `index.html` a la raíz de la rama `main` (puedes subir también este `README.md`).
3. En **Settings → Pages → Build and deployment**, selecciona **Deploy from a branch**.
4. Elige **main** y **/(root)**, y pulsa **Save**.
5. Abre la dirección que aparezca en GitHub Pages, normalmente `https://USUARIO.github.io/NOMBRE-REPOSITORIO/`.

## Video de sustentación

El único video colectivo está integrado en el apartado **Defensa**, mediante el enlace proporcionado: https://dai.ly/xbv08c6. La dirección utilizada para la incrustación es `https://www.dailymotion.com/embed/video/xbv08c6`. También se incluye un enlace externo de respaldo.

**Aviso técnico:** La documentación actual de Dailymotion indica que determinados reproductores embebidos requieren un **Player ID** propio y podrían devolver HTTP 403 sin él. Si el iframe no reproduce el video al publicarlo, consigue el código oficial de inserción desde Dailymotion Studio (incluyendo tu Player ID) y sustituye el atributo `src` del iframe dentro de `index.html`. El enlace de respaldo seguirá funcionando de forma independiente de la incrustación.

## Dependencias

Todo el contenido académico, las imágenes ilustrativas de los banners y el archivo Word descargable están integrados en un único `index.html`. Las fuentes, los iconos, algunos logotipos institucionales, los enlaces a la biblioteca y el video se cargan desde servicios externos: para verlos se necesita conexión a Internet y disponibilidad de esos servicios. La página no constituye un sitio oficial del Campus Virtual institucional.
